# 🍪 Cookie Manager

**Cookie Manager** — минималистичное расширение для браузера, которое позволяет сохранять, загружать и управлять куками (cookies) на любых сайтах.

<img width="338" height="414" alt="image" src="https://github.com/user-attachments/assets/37ba2e8d-46a1-49ac-8ff6-46ff3bd4a0f8" />


## Возможности

- 💾 **Сохранять куки** текущего сайта в JSON-файл
- 📂 **Загружать куки** из файла и восстанавливать сессию
- 📋 **Копировать все куки** в буфер обмена
- 🗑️ **Очищать куки** для любого сайта

## Установка

### 🔧 Установка из исходников (для разработчиков)

1. **Скачайте или склонируйте репозиторий:**

   ```bash
   git clone https://github.com/netkaruma/Cookie_manager
или просто скачайте ZIP-архив и распакуйте его.

2. **Откройте страницу расширений в браузере**

    - Chrome: chrome://extensions/
    - Edge: edge://extensions/
    - Яндекс.Браузер: browser://extensions/

3. **Включите "Режим разработчика" (Developer mode) — переключатель в правом верхнем углу.**

4. **Нажмите "Загрузить распакованное расширение" (Load unpacked).**

5. **Выберите папку с расширением (Cooker_manager)**

6. **Готово! Иконка расширения появится в правом верхнем углу браузера.**
